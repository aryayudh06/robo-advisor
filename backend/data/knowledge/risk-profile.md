# Profil Risiko (Risk Profile)
Profil risiko merangkum seberapa besar fluktuasi investasi yang dapat dan mau diterima investor. Aplikasi ini memakai tiga profil: Konservatif, Moderat, dan Agresif.
Profil dihitung oleh mesin risiko aplikasi; asisten hanya menjelaskan dan tidak mengubahnya.
Setiap profil memiliki lima paket portofolio. Dalam satu profil, paket bernomor lebih tinggi mengambil risiko lebih besar dengan expected return lebih tinggi. Jawaban pada alur tanya-jawab dapat menaikkan atau menurunkan paket di dalam profil, tetapi tidak berpindah profil.
