# Standar Deviasi (Standard Deviation)
Standar deviasi (Std Dev, volatilitas, atau "risiko" di aplikasi ini) mengukur seberapa lebar return portofolio menyebar di sekitar rata-ratanya. Nilai lebih tinggi berarti return lebih sulit diprediksi.
Ini ukuran variasi, bukan batas kerugian maksimum: hasil aktual bisa berada di luar rentang biasanya, dan ukuran ini tidak menunjukkan arah naik atau turun. Saat pasar turun, portofolio dengan standar deviasi lebih tinggi cenderung bergerak lebih besar.
