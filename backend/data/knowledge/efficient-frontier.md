# Efficient Frontier (Batas Efisien)
Efficient frontier adalah kumpulan portofolio yang memberi expected return tertinggi untuk setiap tingkat risiko (atau risiko terendah untuk setiap tingkat return). Portofolio di garis ini tidak bisa diperbaiki pada satu sisi tanpa memperburuk sisi lainnya.
Bergerak naik di garis ini berarti menerima risiko lebih besar untuk expected return lebih tinggi. Setiap paket di aplikasi ini adalah satu titik pada kurva tersebut, dihitung dari data simulasi.
