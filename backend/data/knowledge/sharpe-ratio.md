# Sharpe Ratio
Sharpe Ratio mengukur return per unit risiko: selisih expected return terhadap suku bunga bebas risiko, dibagi standar deviasi. Nilai lebih tinggi berarti return lebih besar untuk setiap unit risiko.
Paling tepat dipakai untuk membandingkan portofolio satu sama lain. Suku bunga bebas risiko di balik nilai simulasi aplikasi ini tidak terdokumentasi di basis pengetahuan.
