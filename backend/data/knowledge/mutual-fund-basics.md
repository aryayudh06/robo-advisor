# Dasar Reksa Dana (Mutual Fund)
Reksa dana mengumpulkan dana banyak investor untuk diinvestasikan pada kumpulan aset. Aplikasi ini mengelompokkan aset menjadi empat kelas: Pasar Uang, Pendapatan Tetap, Saham, dan Lainnya.
Reksa dana pasar uang umumnya paling stabil, sedangkan reksa dana saham umumnya paling berfluktuasi. Nilai investasi dapat naik maupun turun dan hasil tidak dijamin.
